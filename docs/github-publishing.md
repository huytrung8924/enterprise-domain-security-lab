# Đưa project lên GitHub

1. Giải nén bộ project.
2. Tạo repository tên **`enterprise-domain-security-lab`**.
3. Tải **nội dung bên trong thư mục project** lên để `README.md` nằm ở thư mục gốc. Không chỉ tải file ZIP.
4. Commit, mở README và kiểm tra ảnh cùng các liên kết.
5. Có thể ghim repository lên profile.

## About

**Description:**

Enterprise domain lab with AD DS, DNS, SMB, GPO, IIS, mail, OpenVPN, OPNsense/Suricata, and Wazuh/Sysmon monitoring with documented security tests.

**Topics:**

`active-directory`, `windows-server`, `group-policy`, `opnsense`, `suricata`, `wazuh`, `sysmon`, `openvpn`, `network-security`, `siem`, `homelab`, `cybersecurity-lab`

README và tài liệu kỹ thuật bằng tiếng Anh theo phong cách các project mẫu. Nội dung bám báo cáo, bao gồm cả hạ tầng, dịch vụ, quản trị tập trung, giám sát và ba demo bảo mật. Ảnh được trích nguyên bản từ PDF; mỗi ảnh có trang nguồn trong evidence index.
